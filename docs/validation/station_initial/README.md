# 駅コンコース初回物理評価（2026-11-10）

架空の30 m×14 mの駅に柱6本・改札6台・ベンチ4台を配置し、公式G1 ONNXによる二足歩行を評価しました。
人物はJuPedSim 1.4.2のCollisionFreeSpeedModelで相互回避し、G1の実測位置も半径0.45 mの円として反映します。
対象速度0.4 m/s、距離設定1.5 m、水平視野140度、観測距離8 m。
20・30人の通行人希望速度は0.60～0.96 m/s、50人では0.90～1.44 m/sです。

6条件すべて60秒完走、転倒・MuJoCoでの人／設備接触はゼロ。見失い中の速度指令はすべてゼロ。
ロボット占有円の更新失敗も全条件ゼロでした。
20人・30人は4条件合格。50人の2条件は遮蔽後に追従距離が開き、可視率と距離の基準を満たしませんでした。
これは混雑時の追従性能の限界を示す結果であり、50人に対応済みとは扱いません。
対象人物も60秒内には最終目的地へ到達していません。経路の全行程成功率の評価ではありません。

判定条件は、時間完了・転倒なし・接触なし・移動5 m超・平均追従距離2.5 m以下・最終距離3.5 m以下・
対象距離0.85 m以上・平面クリアランス非負・対象可視率70%以上・見失い時ゼロ指令・占有円更新失敗ゼロです。
これらは今回の回帰試験用の基準であり、駅での安全基準や実機の保証ではありません。
`station_validate` は上記の2条件失敗を反映し、終了コード1になります。

検証環境: WSL2 Ubuntu 22.04、Python 3.11.18、MuJoCo 3.3.7、ONNX Runtime 1.22.0 CPU、NumPy 2.2.6、
JuPedSim 1.4.2、Shapely 2.2.0。既存機能・実ONNX・駅の遮蔽・情報遮断・群衆再現性・改札接触を含む33テスト通過。
WSLg表示付き3秒起動とEGL静止画の生成も確認しました。

再実行手順は [STATION.md](../../../STATION.md)。`report.json` と `settings.json` は各条件のディレクトリに保存しています。
10 Hzの全軌跡ログは納品の `station-logs.zip` に収録しています。
人数は同時在場の上限であり、退出後の補充を含む累計流入人数とは異なります。
地図・通行人の位置と速度は正解値を使用。対象だけ視野と中心視線の遮蔽を判定し、不可視中の正解情報を制御へ渡しません。
カメラ検出・再識別、写実的な人体、実測駅人流との校正、待ち行列、手荷物・集団行動は未実装です。
人物は平面の群衆モデルと運動学的コライダー、G1への反応は10 Hzの円近似（更新時0.02秒の空白）です。
対人クリアランスは床面円の近似であり、全身表面間の最小距離ではありません。
