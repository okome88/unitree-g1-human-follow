# G1の学習済み歩行モデル

`g1_terrain_walk/2026-11-07_08-33-29/` に、既存のローカル学習実験から選んだモデルを保存しています。Unitree公式の公開モデルをダウンロードしたものではありません。

|ファイル|内容|
|---|---|
|`model_2999.pt`|保存済み実験で最も反復番号が大きいチェックポイント。最良性能を測定して選抜したものではありません|
|`policy.onnx`|同じ実験フォルダーに保存されていた `2026-11-07_08-33-29.onnx` を改名してコピーしたもの|
|`params/env.yaml`|保存済み環境設定|
|`params/agent.yaml`|保存済みPPO・ネットワーク設定|
|`manifest.json`|元ファイルの場所、バイト数、SHA-256|

元ファイルは `transfer/2026-11-07_08-33-29/` に残しています。途中のチェックポイントとTensorBoardログは登録していません。

## 対応条件

- 既存コードの対象環境はMJLab 1.6.0。
- 保存設定は地形歩行、前進0.4 m/s固定、横移動・旋回指令0。
- Actorの地形観測、関節順序、正規化、行動尺度、PD設定を合わせて使用する必要があります。
- `model_2999.pt` は既存評価コードで使うチェックポイントです。TorchScriptとしての直接読み込み用とは限りません。
- ONNXとチェックポイントの出力一致、ONNXの外部データ依存、実際の歩行性能は未検証です。ONNXは同一実験内の保存ファイルとして収録し、最終チェックポイントからの書き出しと断定しません。
- 4 km/hの歩行、停止、旋回、人間追従への適合は未検証です。

収録時には元ファイルとコピー先のSHA-256一致を確認しています。モデルの読み込み・シミュレーション実行は今回の収録作業には含みません。
