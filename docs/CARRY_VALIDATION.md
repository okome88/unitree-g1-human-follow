標準物理刻みは2 ms。半減時の最大傾き差は約0.02度、到達時間差は約0.02秒でした。
無負荷0.15 m/s歩行も20秒間転倒せず、約2.68 m前進しました。
動画の生成と640×480描画を確認しました。`carry_preview.jpg`は実行開始5秒後の描画です。

これは各条件1回の決定論的動作確認です。実機能力、統計的成功率、未知条件への頑健性は検証していません。
人間モデルは同じ剛性・減衰を使用しています。指定の2 kgで動いたことは、実機で2 kg搬送できる証明ではありません。
人間の横方向変化は横移動で追従し、荷物の向きを変える旋回は行っていません。

## 自動テスト

9件: 設定の異常値、ばね力の向きと上限、座標変換と速度制限、人間停止、反力の整合とreset再現、代理モデルの搬送終了、質量に応じた支持力、G1無負荷歩行、G1軽荷物搬送。
G1初期配置で荷物の接触貫通がないことも確認します。

GitHub ActionsにはUbuntu上での同じ試験を設定。最新の実行状態はリポジトリのActionsを参照してください。
Windowsのサンドボックス端末では一部実行のプロセス終了時に`pyreadline3`のコンソール破棄警告が出ましたが、テスト・物理計算は正常終了しています。

## 再現

```bash
uv sync --frozen --extra dev --extra video
uv run --frozen g1-carry fetch-assets
uv run --frozen --extra dev python -m pytest -q
uv run --frozen python scripts/benchmark_carry.py
```

数値はプラットフォーム・物理ライブラリにより小さく異なる可能性があります。
チェックポイント、重み、設定の取り違えを防ぐため、記録されたmetadataと方策ハッシュを比較してください。
